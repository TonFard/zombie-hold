# 雨夜便利店 · 资产交付说明（给 Blender 建模）

平台页面：`npm run dev` 后打开 http://127.0.0.1:5173/assets.html

每个资产的尺寸、三角形预算、节点名、动画名都在平台右侧"规格"里，也可以看 `catalog.json`。

## 放哪里

| 资产 | 路径 |
|---|---|
| 没有款式的 | `models/<资产 id>.glb`，例如 `models/atm.glb` |
| 有款式的（商品 SKU、贩卖机颜色…） | `models/<资产 id>/<款式 id>.glb`，例如 `models/goods_bottle/bottle_01.glb` |

放进去刷新页面，平台自动识别为"已交付"并逐项校验，不用改 `catalog.json`。还没定稿的文件可以直接拖进视口，按当前选中资产的规格校验，不会写进目录。

## 导出约定

- 单位米，1 BU = 1 m。导出前应用全部变换（Ctrl+A → 全部变换）。
- 正面朝 +Z，也就是 Blender 里朝 −Y。导出 glTF 时保持"+Y 向上"（默认）。
- 原点在底面中心（贴地、水平居中）。目录里标了"原点按约定"的以说明为准，例如路灯原点在杆底，吸顶灯原点在顶面。
- 格式：glb。不导出相机和灯光。材质用 Principled BSDF。
- 贴图：固有色 / 法线（OpenGL，绿色向上）/ ORM（R = AO，G = 粗糙度，B = 金属度）。商品 ≤ 512 px，其他 ≤ 2048 px。
- 自发光（招牌、灯条、屏幕）用 Emission，强度 1 左右。玻璃用 Alpha Blend。

## 可动部件和动画

- 可动部件做成单独对象，名字按目录里的节点名（例如 `cooler_door_01`、`lid`、`screen_balance`）。转轴放在铰链上。
- 开关类（toggle）只做"打开"一段，平台倒放就是关。
- 每扇门各自独立的（perNode）：动画名 = 节点名 + 后缀，例如 `locker_01_open`。
- 切换类（state）不需要动画，几个节点同位置叠放，平台切换显示哪一个。
- 拿取（pick）和游戏逻辑（code）不需要动画，节点名对上就能在平台上点。

## 参照样例

`samples/` 里有 4 个平台自带的样例（ATM、贩卖机、快递柜、罐装饮料）。几何很简单，但节点、动画、尺寸、原点都按约定做好，可以在 Blender 里导入看结构。正式模型交付后会自动替换样例。

## 改规格

改 `scripts/tools/catalog/*.ts` 后运行 `npm run assets:catalog`，重新生成 `catalog.json`。商品的 SKU 名字和价格直接读游戏代码，和场景一一对应。
