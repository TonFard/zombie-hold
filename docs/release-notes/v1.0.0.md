## 黎明 Dawn v1.0.0

第一人称僵尸据点防守。白天搜刮、建造，夜里守住发电机，撑过 10 夜。

### 下载

- **Dawn-Setup-1.0.0.exe**：安装版
- **Dawn-Portable-1.0.0.exe**：免安装，双击直接运行

需要账号登录，进度保存在线上。

### 这一版的内容

**随身武器**
- 军械库新增「随身武器」：开局就带着一把已解锁的武器，出征页选带哪一把
- 要先解锁霰弹枪才能买，150 勋章（比解锁霰弹枪贵、比解锁突击步枪便宜）
- 手枪不能当随身武器；带的那把枪在工坊里不能再买一次，等级照样能升到它自己的上限

**更新不再清进度**
- 从这一版起，更新游戏不会再清空玩家数据：勋章、解锁、熟练度、成就都保留
- 旧版本留下的存档照样能读；认不出的项目（被删掉的、级数超过上限的）只忽略那一项，不会因此丢掉整份存档

**双持手枪平衡**
- 双持换弹时间 ×1.5（两把都要装弹），不再几乎和单持一样快
- 双持重量翻倍（1.0 kg → 2.0 kg），减重强化之后同样是两把的重量，影响携带与跑动
- 双持枪口火焰和补光缩小一半；火光现在出现在实际开火的那把枪上，右手开火时不再出现大片过曝
- 军械库 3D 预览在解锁双持后改用双枪模型，两把前后错开，转到任何角度都看得出是两把

**武器展示与模型**
- 武器台旋转展示按画面比例取景，手枪不再撑满台面，长枪也不会出框
- 第一人称武器模型整体缩小一档，手枪等武器不再顶满屏幕

**场景与资产**
- 便利店「爆发后」场景重做并接入游戏
- 原子资产生成管线打通，新增资产平台页面
