## 黎明 Dawn v1.2.0

第一人称僵尸生存。这一版在原来的守城模式之外，加了三个新模式：生存世界、生化模式、8v8 对战。

### 下载

- **Dawn-Setup-1.2.0.exe**：安装版
- **Dawn-Portable-1.2.0.exe**：免安装，双击直接运行

守城模式需要账号登录，进度保存在线上；从 1.1.0 更新不会清进度。生存世界的进度存在本机。

### 新模式

**生存世界（主菜单 →「生存世界」）**
- 一张可以一直走下去的开放地图：加油站、小镇、农场、货场、检查站、军事基地，房子都能进去搜。
- 空手开局。枪很少，每种枪用自己的子弹；吃的、喝的、药、保暖的东西都要自己找。
- 会饿、会渴、会冷，会下雨下雪。天黑以后丧尸多一倍。
- 离起点远了会遇到带枪的幸存者，他们看见你就开枪，会找掩体、会包扎。
- 加油站、货场、检查站、军事基地各有一台发电机：按住 F 发动，守住几波丧尸，换一大堆补给。
- 按键：Tab 背包，E 拾取，1 2 3 换武器，R 换弹，Q 手雷，4–8 吃喝用药，T 手电，B 武器图鉴，M 地图，F4 切画质。

**生化模式（主菜单 →「生化模式」）**
- 你和 7 个带枪的幸存者被困在镇上，20 秒后其中一个变成母体，被咬中的人也会变成感染者。
- 撑到天黑（4 分钟）还有人活着，人类赢。你被感染了就换到感染者一边，用爪子去抓剩下的人。
- 每局结算给军功，可以换图鉴里还没解锁的枪。

**8v8 对战 · 北港仓库（主菜单 →「开始生存」→ 出征页右下的「8v8 对战」）**
- 8 对 8，先赢 8 局，第 7 局后换边；死了不复活，看队友打完这一局。
- 每局开头按 B 买枪：开局 $800，赢一局 +$3000，输了也有补贴。46 把枪分成 7 类。
- 人机有普通 / 困难 / 专家三档，会蹲、会跳、会找掩体、会扔雷、会捡地上更好的枪。
- 所有人 100 血、同一套枪的数值，守城模式里的强化和加成在这里都不算。
- 按键：空格跳（能跳上箱子），1 / 2 / 3 主武器 / 手枪 / 匕首，V 快速挥刀，G 手雷，E 捡枪。备弹有限，打光就没有。

### 三个模式共用的武器图鉴

- 生存世界里捡到一把枪，这个型号就解锁；守城模式里已经解锁的也会显示在图鉴里。
- 图鉴里点「同步到守城模式」以后，这边解锁的型号才会写进你的守城进度；不点就只读不写。

### 其他改动

- 僵尸、士兵和第一人称的手都重新建了模；僵尸倒下有了不同的死法。
- 狙击枪和高阶步枪装上了瞄准镜，没有镜的枪用机械瞄具。
- 桌面版主菜单多了「生存世界」「生化模式」两项。

### 已知问题

- **这一版的生存世界里没有车。** 皮卡的模型不能随安装包分发；目标里提到皮卡的那一条，捡到一桶汽油就算完成，改装件捡到了暂时没有用。
- 三个新模式都是第一版，平衡还没有调：带枪的幸存者对空手的玩家很致命，8v8 里狙击枪偏强、冲锋枪和霰弹枪偏弱。
- 第一次走进小镇时可能卡一下。
