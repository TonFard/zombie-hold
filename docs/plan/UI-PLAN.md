# 《黎明》UI 全面重做方案

> **版本**：v1.0（2026-11）  
> **现状**：菜单像网页管理后台，不像 FPS 丧尸生存游戏。  
> **目标**：重建整个 UI 系统，让界面像玩家在末日世界中使用的指挥终端。

---

## 一、设计定位

### 1.1 核心原则

UI 是游戏世界的一部分，不是覆盖在游戏上面的网页。玩家打开菜单时，应该感觉自己在操作一台末日据点的战术终端——半透明面板浮在 3D 场景之上，信息以军事简报的形式呈现，每个交互都有操作反馈。

**不要的**：纯黑背景、网页表单按钮、滚动长列表、管理后台布局。  
**要的**：深色半透明面板、3D 实时背景、战术信息展示、军事风格排版。

### 1.2 参考游戏

| 游戏 | 参考什么 | 不参考什么 |
|------|---------|-----------|
| **逃离塔科夫** | 装备管理、仓库网格、武器改装界面、军事风格信息布局 | 过于复杂的层级嵌套 |
| **全境封锁 2** | 装备详情面板、属性进度条、交互层级、模块化 UI | 橙色主色调 |
| **使命召唤：现代战争** | 主菜单动态背景、任务选择、战术信息展示、过场感 | 多人大厅结构 |
| **僵尸毁灭工程** | 末日生存氛围、物资管理、生存系统的信息表达 | 像素风 |

### 1.3 视觉定位

- **整体**：写实军事末日风格
- **背景**：Three.js 实时 3D 场景，不是静态图片
- **UI**：深色半透明面板，不是整块纯黑色
- **操作反馈**：每个按钮有 hover/active 状态变化，重要操作有音效

## 二、视觉语言规范

### 2.1 色板

| 用途 | 色值 | CSS 变量 | 使用场景 |
|------|------|---------|---------|
| **暗金（主色）** | `#d9c9a0` → `#f0b83a` | `--hud-gold` | 选中态、军衔、等级、重要信息、已完成 |
| **危险红** | `#e8553f` | `--hud-danger` | 警告、战斗、生命值低、危险区域 |
| **科技蓝绿** | `#6fd0e8` | `--hud-tech` | 科技信息、状态值、资源数量、补给 |
| **成功绿** | `#6fcf8a` | `--hud-success` | 数值提升、完成标记 |
| **面板背景** | `rgba(8, 12, 18, 0.82)` | `--panel-bg` | 所有面板底色 |
| **面板边框** | `rgba(255, 255, 255, 0.1)` | `--panel-border` | 面板描边 |
| **正文** | `#d8dee4` | `--text-primary` | 主要文字 |
| **辅助文字** | `#8f9aa6` | `--text-muted` | 次要说明 |

### 2.2 字体

```css
:root {
  /* 中文：系统黑体，清晰锐利 */
  --font-cn: 'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC', sans-serif;
  /* 英文/数字：等宽军事风格 */
  --font-mono: 'JetBrains Mono', 'Fira Code', 'Consolas', monospace;
  /* 标题英文：宽间距大写 */
  --font-title: var(--font-mono);
}
```

- 中文用现代黑体，不用宋体/楷体
- 英文和数字用等宽字体，配合 `letter-spacing`
- 标题英文全大写 + 宽间距（`letter-spacing: 6–12px`）
- 数值用 `tabular-nums` 防止宽度跳动

### 2.3 面板风格

```
┌─ 面板标题 ──────────────────┐    ← 顶部细线 + 标题嵌在线上
│                              │    ← 内容区域
│  背景 rgba(8, 12, 18, 0.82)  │    ← 半透明，能看到后面的 3D 场景
│  backdrop-filter: blur(8px)  │    ← 毛玻璃
│                              │
└──────────────────────────────┘    ← 底部细线
```

- 面板不是整块纯黑，要能隐约看到后面的 3D 场景
- 边框用 1px 的 `rgba(255, 255, 255, 0.1)`，不是实线
- 选中 / 激活状态的面板边框变成金色或红色
- 重要面板角落加战术角标 `⌜` `⌝` `⌞` `⌟`（伪元素实现）

### 2.4 装饰元素

- **战术角标**：面板四角的 L 形装饰线（2px 宽，8–12px 长），用 `::before` / `::after` 实现
- **扫描线**：面板顶部或底部一条 1px 高的水平渐变线（从透明到主色再到透明），用做分隔
- **战术标签**：标题前面加 `[` `]` 或 `//` 前缀，英文全大写
- **数据标签**：`KEY: VALUE` 的等宽排列，冒号对齐
- **脉冲光标**：输入状态用闪烁的 `_` 光标

### 2.5 过渡动画

- 页面切换：`opacity 0→1` + `translateY(8px→0)` 组合，时长 `200ms`
- 面板展开：`max-height` + `opacity` 组合
- 按钮 hover：边框颜色 + 背景色过渡 `150ms`
- 数值变化：数字用 `transition` 过渡，不是瞬间跳变
- 禁止使用 `ease-in`（感觉迟钝），统一用 `ease-out` 或 `cubic-bezier(0.25, 0, 0.2, 1)`

### 2.6 按钮规范

| 类型 | 用途 | 样式 |
|------|------|------|
| **主按钮** | 出征、开始任务 | 红色描边 + hover 填充 + 宽间距大字 |
| **次按钮** | 训练场、每日挑战 | 白色描边 + hover 变蓝绿 |
| **购买按钮** | 花费勋章/补给 | 金色描边 + 价格图标 |
| **幽灵按钮** | 返回、取消 | 透明 + 细描边 |
| **禁用按钮** | 条件不满足 | 灰色描边 + `cursor: not-allowed` + `opacity: 0.5` |

所有按钮 `hover` 时有 `box-shadow` 辉光（颜色与描边一致，`blur 20–30px`，`opacity 0.3–0.5`）。

### 3.1 标题页（P0）

**文件**：`src/ui/screens/MainMenu.vue`

#### 现有问题

1. "黎明"两个字占比太大，但没有品牌感
2. 英文 "DAWN" 和中文标题之间的关系不协调
3. 背景过暗，看不清 3D 场景
4. "进入据点"按钮像网页表单按钮
5. 五组音量滑块 + 灵敏度 + 画质直接堆在首页，占了大量空间
6. 右侧"操作"和"玩法"面板把首页变成了说明书

#### 具体改动

| 现有 | 改为 |
|------|------|
| "黎明" 92px + "DAWN" 40px 分两行 | "黎明" 作为品牌 Logo（64px），下方 "DAWN · SURVIVAL PROTOCOL"（16px 等宽大写宽间距） |
| "守住发电机，撑过十个夜晚" | "黎明之后，没有安全区。" + 动态的存档天数和地点 |
| "进入据点"一个大按钮 | 5 个菜单项纵向排列：继续/新游戏/读档/设置/退出 |
| 五组音量滑块 + 灵敏度 + 画质 | 全部移进「设置」页面 |
| 右侧操作说明面板 | 删除（移到游戏内 loading 提示或暂停菜单） |
| 右侧玩法说明面板 | 删除（移到游戏内 loading 提示） |
| 战绩（最远 / 击杀 / 通关） | 保留，放在底部状态栏或菜单下方小字 |
| 背景 `linear-gradient` 覆盖 | 只在左侧做渐变遮罩（40%），右侧透出 3D 场景 |

#### 3D 背景

- 复用现有的游戏场景（`buildOutpost`），但用一个独立的电影镜头控制器
- 相机高度 8–12 米，绕发电机缓慢公转（一圈 90 秒）
- 黄昏光线（`DUSK` look），轻微偏暖
- 远处 3–5 只僵尸沿预设路径缓慢游荡（只是剪影，不需要完整 AI）
- 雾气粒子（低频，20–30 个半透明粒子在近地面飘）
- 发电机灯光轻微明灭（`intensity` 在 0.9–1.1 之间正弦波动）
- 不需要路灯闪烁（已修掉了）

### 3.2 据点 / 出征页（P0——问题最大的页面）

**文件**：`src/ui/screens/Lobby.vue`（`deploy` tab 部分）

#### 现有问题

1. 章节、难度、随身武器、当前加成、出征、训练场、每日挑战全部堆在一个滚动面板里
2. 这些功能模块属于不同的决策层级，混在一起信息密度不合理
3. 右侧大面积的 3D 背景完全没有利用
4. 章节锁定状态太灰暗，分不清"未解锁"和"不可用"

#### 三栏详细说明

**左栏：任务列表**（宽度 220px，固定）

- 标题 `[MISSIONS]` 或 `任务列表`
- 每个章节一张卡片，纵向排列
- 卡片内容：编号（`01` 等宽）、章节名、地点描述、状态
- 状态区分：
  - **已通关**：正常亮度 + 绿色 `✓` 标记
  - **当前选中**：暗金边框 + 轻微背景高亮
  - **已解锁未通关**：正常亮度
  - **未解锁**：降低亮度 50% + 🔒 图标 + 解锁条件文字
- 卡片可点击选择

**中栏：地图预览**（flex: 1，自适应宽度）

- 上半部分：章节地图的 3D 俯视图（或截图），占据主要空间
- 下半部分：章节名 + 数值概览（僵尸倍率、零件倍率等），一行标签
- 地图预览方案：
  - 优先：3D 场景的俯视摄像机（45° 倾斜，缓慢旋转）
  - 备选：`docs/plan/img/map_now.png` 之类的预渲染截图

**右栏：任务简报**（宽度 300px，固定）

- 标题 `[BRIEFING]` 或 `任务简报`
- 章节名 + 地点描述
- 威胁等级（图标 + 文字）
- 预计时间
- 分隔线
- 任务目标列表（编号列表）
- 分隔线
- 难度选择（紧凑的按钮行，3 个）
- 随身武器选择（紧凑的按钮行）

**底栏：操作栏**（固定在底部）

- 左侧：训练场、每日挑战、5v5 团队死斗（次按钮）
- 右侧：「开始任务」大按钮（主按钮，红色描边）
- 有检查点时在底栏左上显示「继续上一局」选项

**当前加成**

- 不再内联在出征面板里
- 改成顶栏右侧的一个可展开的状态指示器
- 默认折叠显示关键数字（武器数、炮塔上限）
- 点击展开完整加成列表

- 滚轮缩放（0.5×–2.0×）
- 模型下方叠加信息：
  - 武器名称（大号 + 英文副名）
  - 武器定位（"备用武器 · 近距离自卫"）

**右栏：Tab 信息面板**（宽度 320px）

- 重量和后坐力用独立的条形图
- 悬停工作台强化线时，属性值显示 `当前 → 升级后`（已有此功能，保留）

**Tab 2：升级路线**

- 每条线：名称 + 进度点 + 当前效果 + 下一级效果 + 升级按钮

**Tab 3：熟练度与升星**

- 每级解锁的效果列表

#### 武器 3D 预览技术方案

现有的 `render/weapons/preview.ts` 已经有武器预览功能（360×140 画布），需要扩展：

1. 画布尺寸改为自适应容器（`ResizeObserver`）
2. 新增自动旋转：`autoRotate = true`，每帧 `mesh.rotation.y += dt * 0.52`
3. 鼠标交互：`pointerdown` 停止自动旋转，`pointermove` 拖动旋转，`pointerup` 3 秒后恢复
4. 滚轮缩放：调整相机 `fov` 或 `position.z`
5. 背景：径向渐变（蓝绿色微光），匹配整体风格

### 4.2 电影相机控制器

新增 `src/render/core/cinematic.ts`：

```typescript
interface CinematicShot {
  // 相机围绕的目标点
  target: { x: number; y: number; z: number };
  // 相机到目标的距离
  distance: number;
  // 相机高度
  height: number;
  // 旋转速度（弧度/秒），正值逆时针
  speed: number;
  // 初始角度
  angle: number;
}
```

- 标题页：`{ target: corePos, distance: 22, height: 10, speed: 0.07, angle: 0 }`
- 出征页：`{ target: mapCenter, distance: 35, height: 30, speed: 0.03, angle: -0.5 }`
- 需要平滑切换：切换镜头时用 `lerp` 过渡（1.5 秒）

### 7.4 武器 3D 预览扩展

修改 `src/render/weapons/preview.ts`：

```typescript
interface PreviewOptions {
  width: number;
  height: number;
  autoRotate?: boolean;      // 默认 true
  rotateSpeed?: number;      // 默认 0.52 rad/s
  zoomEnabled?: boolean;     // 默认 true
  zoomRange?: [number, number]; // 默认 [0.5, 2.0]
  resumeDelay?: number;      // 停止拖动后多久恢复自动旋转，默认 3000ms
}
```

- `ResizeObserver` 监听容器尺寸变化，自动更新画布和相机
- 自动旋转用 `requestAnimationFrame`，拖动时暂停
- 背景用径向渐变 `clearColor`

### 7.5 电影相机

新增 `src/render/core/cinematic.ts`：

- `CinematicCamera` 类，包含 `PerspectiveCamera` + 动画逻辑
- `setShot(shot: CinematicShot, transition?: number)` 切换镜头
- `update(dt: number)` 每帧更新
- 与现有的 `CameraRig` 独立，菜单/游戏各用各的

### 7.6 响应式
