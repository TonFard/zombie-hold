M14 · 贴地、接触阴影、AO、声音 已完成（等你回复没声音的细节）

结果（左：改之前 / 右：改之后）

查出来的
  • 车和集装箱的模型本身是贴地的（检查了每个网格）。我原以为皮卡底下的小网格是碎片，实际是车轮，所以没有改落地算法。
  • 真正的缝在叠放集装箱：模型被等比限制压矮后，第二层还按平均高度放，中间空出一条缝。现在按实际高度摞。
  • 音量曲线以前是平方，滑条 20% 实际只有 4%；改成 1.5 次方。手柄 / 触屏也能解锁声音，切回窗口、换耳机后自动恢复。

做什么

项做法验收
落地点按网格面积算底面，而不是全局最低点：面积很小、比主体低很多的碎片（拖车钩、阴影片）不算。和检查脚本共用一个纯函数check:props：每个模型落地误差 < 2% 高度
叠放集装箱第二层放在第一层的实际高度上截图：两层之间没缝
接触阴影车、集装箱、发电机、路障底下一张径向渐变的暗色贴片（InstancedMesh，不写深度），所有画质都开同机位前后截图
GTAOthree 自带 GTAOPass 插在 RenderPass 和 Bloom 之间；高画质开、中画质低分辨率、低画质关同机位前后截图
声音手柄 / 触屏也能解锁；切回窗口时恢复；换输出设备时重建；音量曲线和显示一致；设置页「测试声音」按钮 + 状态audio-check 通过；你实际听

M16 · 武器第二层：枪机、升星、平衡 已完成

M18 · 地图纵深 第一章已完成

地图不扩大，让 80×80 里每块区域都有「去那里的理由」。下面左图是从游戏网格直接画出来的现在的第一章，右图是改造后的规划。

1. 四个街区：各有资源和风险，不只是换模型

街区资源（搜刮点给什么）风险
居民区（西北）补给、医疗包（立刻回血 40）室内狭窄，被堵门
加油站（东北）手雷、燃烧弹；油罐可以引爆爆炸物多，打偏了会炸到自己
仓库（东南）大量零件离据点最远，守卫最多
停车场（西南）熟练度经验（给手上那把枪）车辆迷宫，视线差

2. 道路：环境叙事，不随机撒

  • 每条路 1 个固定场景：北路连环追尾、西路侧翻货车（货物散落）、东路撞断的路灯 + 行李箱、南路警方路障。
  • 场景里的车和隔离墩参与碰撞和寻路（会改变僵尸走法，所以要跑 sim:nav）；碎玻璃、行李箱、垃圾只是装饰，不进网格。

3. 三个危险区：可选、高风险、高收益

距离控制：三处都在离据点 25–35 米内（白天只有 45–60 秒）；每局只开放其中一处（随机，横幅预告），不是一次全开。

4. 远景和氛围

  • 远景：断崖外一圈低模剪影（城市、电塔、山），不参与碰撞和寻路，一次绘制。
  • 粒子：烟、灰尘、火花用对象池，有距离上限；低画质关。

规则 每一步都遵守

逻辑和画面分开视觉模型、碰撞、寻路、阴影各管各的。装饰物（碎玻璃、杂草、贴花）不进网格，不改变僵尸走法。
每步验收vue-tsc、所有 sim:*、check:balance、新加的 check:props / sim:stats 通过；关键机位截图对比。
性能重复模型用 InstancedMesh；粒子和贴花用对象池；不在帧循环里新建材质 / 几何体。
数值新加成必须走来源登记，否则 sim:stats 对账失败；动到成长就重跑 sim:progress。
存档动到存档结构就 SAVE_EPOCH +1。
不做武器配件槽、扩大地图、背包网格、换引擎。
