# 《尸潮 · 死守》重制规划

项目目录：`E:\PythonProject\simplegame\zombie-hold`。旧文件 `尸潮_优化版.html` 不改动，也不复用其中的美术、数值和玩法。

> **进度和待办看第 13 节（路线图）。** 第 1–11 节是第一阶段（已完成）的设计，第 12 节是第二阶段的玩法设计。

## 1. 目标

1. 用前端技术栈重做整个游戏：全新美术、全新玩法、全新地图。
2. 彻底解决旧版僵尸寻路问题（卡在障碍物上、原地蹭墙、绕不过去）。
3. 模型要精细：每种角色、武器、建筑都有可辨认的轮廓和细节，不是几个方块拼起来。
4. 每把武器有自己的升级路线。手枪即使升满，也比其他武器升级一两次后弱。

## 2. 技术栈

| 层 | 选择 | 理由 |
|---|---|---|
| 构建 | Vite + TypeScript | 热更新快，类型检查能挡掉大量低级错误 |
| UI | Vue 3（`reactive` 做状态，不引入 Pinia） | 主菜单、HUD、建造栏、商店、卡牌都是 DOM 界面，用组件写比手写 DOM 清晰 |
| 渲染 | Three.js | 现有经验，生态成熟 |
| 后期 | Three 自带 EffectComposer（Bloom、渐晕） | 灯光和枪口火光需要辉光 |
| 音频 | Web Audio 程序合成 | 不依赖音频素材文件 |
| 存档 | localStorage（JSON，带版本号） | 只存最高夜数、统计和设置 |

游戏逻辑（`src/game`）不依赖 Three.js，只写纯 TypeScript。这样可以在 Node 里无头运行，用来验证寻路和数值平衡。

## 3. 玩法

### 3.1 概述

视角：**第一人称**（眼高 1.62 米，FOV 74°，冲刺时拉宽）。WASD 相对视线方向移动，鼠标转动视角（指针锁定），准星在屏幕中心，左键开火。主菜单背景是围着据点缓慢旋转的环绕镜头。

> 早期版本曾改成斜俯视，那是我擅自做的决定，不符合需求，已改回第一人称。

背景：废弃加油站据点。玩家要保护中央的**发电机**，同时自己不能死。撑过 **10 个夜晚**获胜，第 5 夜和第 10 夜有首领。

### 3.2 一夜的流程

1. **白天（准备，第一天 60 秒、之后 45 秒，Enter 可提前结束；开局赠送 120 零件，第 1 夜只有 12 只，当作教学夜）**
   - 搜刮：地图上的零件箱，走过去拾取。
   - 建造：放置路障、炮塔、地刺。
   - 工坊：购买武器、升级武器（靠近工坊按 F）。
   - 夜晚结束后弹出卡牌三选一。
2. **夜晚（战斗）**
   - 僵尸从 6 个入口分批进入，朝发电机或玩家前进。
   - 击杀掉落零件。
   - 全部清除后进入下一个白天。
3. **失败条件**：玩家死亡，或发电机生命降到 0。

### 3.3 操作

| 按键 | 作用 |
|---|---|
| W A S D | 前后左右移动（相对视线方向） |
| 鼠标 | 转动视角；第一次点击画面锁定鼠标，灵敏度在设置里调（瞄准时随放大倍数自动降低） |
| 左键 | 开火；建造模式下在准星指的格子放置 |
| 右键 | 瞄准（缩小散布、放大视野、移速降低、不能冲刺）；建造模式下拆除准星指的建筑 |
| R | 换弹（弹匣里还有子弹时是战术换弹，快 15%） |
| 1–7 | 切换已拥有的武器（建造模式下 1/2/3 选建筑） |
| Shift | 冲刺（消耗体力；松开后有短暂的抬枪时间） |
| C | 蹲下（降低视线高度、散布更小、移速更慢）；冲刺中按 C = 滑铲 |
| V | 近战（枪托砸，55 伤害，击退） |
| F | 开关建造模式（右键或 X 拆除，返还 70%） |
| E | 靠近工坊时打开 / 关闭武器工坊；否则修理附近的建筑（每 10 点生命花 1 零件） |
| Enter | 白天提前开始夜晚 |
| Esc | 释放鼠标并暂停 |

**第一人称的取舍**

- 命中判定是真 3D 弹道（M6）：子弹从眼睛高度出膛、有初速和下坠，头部是单独的球体（爆头倍率），路障 / 沙袋 / 车辆按真实高度挡子弹，可以越过矮掩体打头。寻路仍在 2D 网格上跑。
- 看不到身后，所以右上角有雷达：玩家在中心，视线朝上，显示僵尸（颜色区分种类）、发电机、建筑、零件箱、工坊和地形；首领超出范围时贴在圆边提示方向。
- 被打时屏幕上出现红色扇形，指向攻击者的方位，并随转头实时更新。命中、击杀、暴击有不同的准星标记。
- 建造模式沿视线找准星指的格子（先碰到的地面、建筑或墙），绿框可建、红框不可建，准星同时变色。
- 鼠标没锁定（刚恢复、浏览器拒绝了锁定）时模拟暂停，并提示"点击画面，继续游戏"，不让僵尸白打人。

### 3.4 僵尸

数值是初值，按波次再乘以生命系数 `1 + 0.10 × (夜数 − 1)`。

| 类型 | 生命 | 速度 | 伤害 | 掉落 | 出现 | 特点 |
|---|---|---|---|---|---|---|
| 行尸 | 60 | 1.6 | 10 / 秒 | 3 | 第 1 夜 | 基础单位，驼背前伸双臂 |
| 奔袭者 | 35 | 3.6 | 7 / 0.6 秒 | 4 | 第 2 夜 | 瘦长，冲刺姿态，优先追玩家 |
| 肿胀者 | 220 | 1.1 | 18 / 秒 | 10 | 第 3 夜 | 死亡时爆开酸液，范围 2.2，伤害玩家和建筑 |
| 破墙者 | 160 | 1.5 | 对建筑 ×3 | 8 | 第 4 夜 | 举盾拖锤，优先攻击建筑 |
| 巨像（首领） | 2400 / 6500 | 1.0 | 重击范围伤害 | 150 | 第 5 / 10 夜 | 3 倍体型，周期性冲锋，带随从 |

每夜僵尸数量：`round(12 + 5.5·n + 0.35·n²)`，同屏上限 70（性能预算）。

### 3.5 建筑

| 建筑 | 成本 | 生命 | 说明 |
|---|---|---|---|
| 木制路障 | 15 | 220 | 占 1 格，阻挡通行。生命低于 66% 和 33% 时模型会掉木板 |
| 自动炮塔 | 90 | 150 | 射程 9，不耗弹药，会旋转炮管，优先打离发电机最近的僵尸 |
| 地刺 | 30 | 25 次触发 | 不阻挡，僵尸走过去受伤，持续伤害 |

建筑只能放在可建造区域：内院，以及各入口外侧 8 格内。

### 3.6 武器与升级路线

5 把武器，每把有 5 级升级，路线固定，第 5 级是该武器的招牌能力。手枪第 5 级只有数值提升，没有特殊能力。

持续 DPS 公式：`伤害 × 弹丸数 × 弹匣 ÷ (弹匣 ÷ 射速 + 换弹时间)`。霰弹枪按弹丸全部命中计算，范围伤害、穿透、燃烧不计入。

| 武器 | 购买价 | 升级路线（1 → 5 级） | 招牌能力 |
|---|---|---|---|
| M9 手枪 | 起始 | 加长枪管 → 扩容弹匣 → 轻量击锤 → 速装弹夹 → 空尖弹 | 无 |
| 蝰蛇冲锋枪 | 350 | 钢芯弹 → 弹鼓 → 减震枪托 → 高速弹 → 过热弹链 | 持续射击射速最多 +40% |
| 铁砧霰弹枪 | 450 | 加粗弹丸 → 加长管状弹仓 → 十弹丸 → 快速装填 → 龙息弹 | 点燃目标，3 秒持续灼烧 |
| 铁壁突击步枪 | 600 | 精准弹 → 改良导气 → 穿甲弹 → 扩容弹匣 → 三点爆发 | 穿透 2 个目标 |
| 炼狱榴弹发射器 | 1100 | 高爆弹 → 扩容弹仓 → 扩大杀伤 → 快速装填 → 集束弹 | 爆炸后分裂为 3 枚小炸弹 |

升级费用：手枪 40 / 60 / 90 / 130 / 180（共 500）；其他武器约为购买价的 0.25 / 0.4 / 0.6 / 0.9 / 1.3 倍。

每级升级会改变模型：加弹鼓、瞄准镜、消音器、前握把、涂装，升级后的武器看得出来。

**手枪最弱的约束（用脚本强制检查）**

初始数值对应的持续 DPS（`scripts/check-balance.ts` 会重新计算，以脚本为准）：

| 武器 | 基础 | 1 级 | 2 级 | 满级 |
|---|---|---|---|---|
| 手枪 | 45.3 | 52.1 | 55.5 | **90.8** |
| 冲锋枪 | 80.6 | 96.7 | 112.3 | 约 175 |
| 霰弹枪 | 77.5 | 96.1 | 110.4 | 约 173 |
| 突击步枪 | 89.4 | 102.8 | 113.1 | 约 169 |
| 榴弹发射器 | 97.3 | 113.5 | 138.0 | 约 192 |

脚本要通过三条检查：

1. 手枪满级的 DPS，低于其他每把武器升 1 级后的 DPS，余量至少 5%。
2. 手枪没有穿透、范围伤害、燃烧、射速递增中的任何一项。
3. 手枪满级的总升级花费，低于任何一把其他武器的购买价加 2 级升级花费。

### 3.7 卡牌

每夜结束三选一，约 16 张，分普通、稀有、史诗三档，权重 70 / 25 / 5。例：最大生命 +20%、移速 +8%、路障生命 +30%、炮塔射速 +20%、零件掉落 +15%、换弹 +10%、暴击率 +8%、发电机自动修复、击杀回血、冲刺不耗体力 3 秒。

### 3.8 经济

只有一种货币：零件。初值：每夜通关奖励 `40 + 20·n`，每夜 8 个零件箱各 10–25，加上击杀掉落。购买和升级的价格表见上。经济平衡需要真人试玩调整，我只能保证数值自洽，不能保证手感。

## 4. 地图

使用 80 × 80 格（每格 1 单位）的手工设计地图，用矩形图元在 `map-outpost.ts` 里搭建，渲染和寻路共用同一份数据。

```
  ┌────────────────────────────────────────┐
  │ [公寓楼 L 形，多门洞]   ╔═══北门(宽6)═══╗   [加油站：雨棚+便利店] │
  │      废弃街区             ║               ║                       │
  │  西 ═══西门(4)═══  ║  发电机 · 工坊  ║ ═══东门(窄3)═══  东    │
  │                          ║  内院 28×28   ║                       │
  │ [停车场：车辆残骸迷宫]    ╚══南墙缺口(瓦砾,8)╝   [仓库+集装箱巷道] │
  └────────────────────────────────────────┘
      S         刷怪点：北左、北右、东、南左、南右、西
```

- **内院**：中央 28 × 28，混凝土围墙，4 个出入口，大小各不相同，不对称。
- **南墙缺口**：墙体塌了一段，地上是瓦砾，可通行但减速。
- **四个街区**：公寓楼、加油站、仓库、停车场，各自形成不同的绕行路线，让玩家可以用路障改变僵尸走向。
- **刷怪点**：6 个，在地图边缘，带雾气和红色信号灯作为视觉提示。
- **零件箱**：8 个，散布在街区里。
- **装饰**：枯树、路灯（部分会亮）、油桶、锥桶、沙袋、栅栏（装饰栅栏不阻挡）、废弃帐篷。
- **边界**：地图边缘是不可通行的断崖和浓雾，镜头夹在范围内。

## 5. 寻路方案（重点）

旧版问题的根源是僵尸直线追玩家，再靠碰撞推开，遇到障碍就卡住。新方案：

1. **网格**：80 × 80，每格有状态：空地、静态障碍、建筑、地刺、瓦砾（减速）。
2. **Flow Field**：从目标出发做 Dijkstra，8 邻接，正交代价 1，斜向 1.414。斜向移动要求两侧正交格都不是障碍，避免擦墙角穿过去。
   - 建筑格可通行但代价高（约 25），所以路径被完全封死时，僵尸选择拆路障，不会堵在原地。
   - 地刺格代价 +3，瓦砾格代价 +2。
3. **两张场**：
   - 发电机场：建造或建筑被摧毁时重算。
   - 玩家场：玩家换格时重算，节流到 8 次/秒。
   - 僵尸默认走发电机场；玩家在其仇恨范围（奔袭者更大）内，则走玩家场。
4. **视线捷径**：目标在 12 格内且网格射线无遮挡时直接走直线，避免绕路抖动。
5. **平滑**：对周围 4 个格子的下降方向做双线性插值，跳过障碍格。
6. **局部避让**：空间哈希找邻居，加分离力；与网格做圆–矩形碰撞并沿墙滑动，而不是停下。
7. **攻击建筑**：下一格是建筑时，僵尸停下来攻击，破墙者伤害 ×3。
8. **卡死检测**：1 秒内位移小于 0.15 且没在攻击，则吸附到格子中心、短暂关闭分离力、重新采样；仍无效则重置路径。

**验证**（`scripts/sim-nav.ts`，Node 无头运行，固定随机种子）：

- 200 只僵尸从 6 个刷怪点出发，跑 120 秒模拟时间。
- 要求：到达率 ≥ 98%；没有僵尸处于障碍格内；最长卡住时间 < 2 秒。
- 场景 A：入口全开。场景 B：4 个入口全部用路障封死，僵尸必须去攻击路障，不能原地闲置。场景 C：中途拆掉路障，路径要重新生效。
- 记录每步平均耗时，150 只僵尸时目标 < 2 ms。

## 6. 美术与模型

整体方向：**黄昏低多边形**。白天是低角度暖光和长阴影，夜晚是冷蓝月光加路灯与发电机的暖光。

### 6.1 模型工具集（`render/models/kit.ts`）

- 基础形体：圆角盒、倒角圆柱、锥台、胶囊、挤出轮廓，不用裸方块。
- 顶点色烘焙环境光遮蔽：越靠近地面和缝隙越暗，加每个部件的随机色偏。
- 同材质部件合并成一个几何体，减少绘制调用。
- 自发光件（眼睛、指示灯、发电机线圈）配合 Bloom。

### 6.2 角色

- 骨架层级：骨盆 → 脊柱 → 胸 → 头；肩 → 上臂 → 前臂 → 手；髋 → 大腿 → 小腿 → 脚。
- 程序动画：待机呼吸、行走、奔跑、攻击（前扑加挥臂）、受击后仰、死亡倒地。
- 变体：肤色、衣服颜色、体型、破损补丁、少一只手、帽子或头发，由随机种子决定。
- 每种僵尸的剪影不同：
  - 行尸：驼背，手臂前伸。
  - 奔袭者：瘦长，前倾。
  - 肿胀者：巨大肚子，带发绿光的脓包，小脑袋。
  - 破墙者：废铁拼的护甲，举盾拖锤。
  - 巨像：3 倍体型，外露肋骨，铁链，胸口红色发光核心。
- 玩家：幸存者，带头盔、头灯、背包、战术背心；每类武器有对应持枪姿势和后坐力动画。

### 6.3 武器

每把武器用 20–40 个部件搭建（机匣、枪管、护木、枪托、弹匣、准星），并随升级等级增加配件。枪口火光用发光面片加瞬时点光源。

### 6.4 建筑与环境

- 路障：木板、沙袋、铁丝网；受损时掉木板。
- 炮塔：底座、可旋转炮塔、双管、弹链、小灯。
- 地刺：尖刺会伸缩。
- 发电机：金属框架、发光线圈、排气烟雾；生命低时闪烁。
- 工坊：台钳、工具墙、台灯。
- 环境：墙体带窗框、檐口、部分塌顶的屋顶；车辆有车厢、车轮、破碎车窗；集装箱有波纹肋条。
- 程序生成的新贴图：沥青裂纹、草地、泥土，以及血迹和焦痕贴花。

### 6.5 光照与后期

一盏带阴影的平行光（2048 阴影贴图，跟随玩家）、半球光、最多 6 个按距离分配的路灯点光源，其余路灯用自发光面片模拟。天空是一个渐变穹顶，黄昏有暖色太阳，夜里是月亮加星星，地平线颜色与雾一致。后期：ACES 色调映射、轻度 Bloom（枪口火光、发电机、月亮会发光）。

第一人称的枪和手在单独的场景里、世界画完后清掉深度再画，所以贴墙或被僵尸挡住时枪不会穿模；它有自己的灯光，亮度比世界略高。

画质三档（主菜单和暂停菜单里切换，存档保存）：

| 档位 | 像素密度 | 阴影 | 后期 / 抗锯齿 |
|---|---|---|---|
| 高 | 最高 1.5 倍 | 2048 | Bloom + 4 倍 MSAA |
| 中 | 1 倍 | 1024 | Bloom + 4 倍 MSAA |
| 低 | 1 倍 | 关 | 关（无抗锯齿） |

## 7. 性能预算

- 目标 60 FPS（中端独显），同屏最多 70 只僵尸。
- 静态地图按 16 × 16 格分块合并几何体；重复道具（木箱、锥桶、树）用 InstancedMesh。
- 总绘制调用 < 700。实测（无头浏览器，64 只僵尸 + 26 个建筑，含阴影通道）：第三人称旧镜头 391 次、约 108 万三角形；改成第一人称后画面内能见到的东西更少，没有重新测。真实显卡上的帧率没有测过。
- 子弹、粒子、伤害数字、血迹贴花全部用对象池。
- 受击闪白通过切换共享的闪光材质实现，不为每只僵尸克隆材质。
- 长时间模拟后场景节点数、几何体和纹理数量稳定，没有泄漏（打了两轮共约 50 只僵尸后对比）。

## 11. 假设与无法自动验证的部分

- 仅支持桌面浏览器、键鼠操作。
- 无头浏览器用软件渲染（约 1–3 帧/秒），帧率数据不代表真实显卡表现，真实 FPS 需要你在自己的机器上看。
- 指针锁定（鼠标转视角）在无头浏览器里没法真正触发。测试时用 `?nolock=1` 假装已锁定，用接口直接转视角、用真实按键验证键盘，鼠标按键用注入的方式验证。真实鼠标的手感、灵敏度默认值、Esc 暂停后再点击恢复这条路径，需要你实际玩一下。
- 音频我听不到，只能确认没有报错、每个音效渲染出来有声音且不爆音、音量逻辑合理。
- 经济和关卡难度需要真人试玩才能调到好玩。机器人试玩用的是俯视时代的策略，改成第一人称后没有重测，难度（尤其是看不到身后）要靠你的体感判断。
- 模型精细程度只能靠截图判断，最终观感以你的眼睛为准。

## 12. 第二阶段：爆头、弹道、右键瞄准、存档、大厅与局外成长

### 12.1 我做的假设（不对请直接说）

- **大厅是一个界面**，背景是围着据点慢慢转的 3D 镜头，不是可以走动的 3D 基地。局外成长的数据和逻辑与界面分开，以后想改成"在基地里走到军械台前按 E"，只需要换外壳。
- **存档 = 局外进度自动保存 + 一局的检查点**。每个白天开始时（含开局）自动保存一次；中途退出后点"继续"，从最近一个白天的开头接着打。夜里退出会丢掉这一夜的进度。只有一个存档位。
- 手枪"即使满级也最弱"的约束继续保留：大厅能把武器等级上限从 5 提到 8，但手枪多出来的 3 级只改手感（瞄准更快、腰射更准、瞄准时不减速），不加伤害。脚本会检查。

### 12.2 爆头

- 每只僵尸有两块命中体积：身体是竖直圆柱（半径同碰撞半径，高 1.7–3.9 米），头是一个球（行尸 半径 0.19 米，位于 1.62 米高、朝前 8 厘米）。子弹先判头，再判身体。
- 爆头伤害 = 伤害 × (1 + (武器爆头倍率 − 1) × 僵尸头部脆弱系数 × 卡牌加成)。

| 武器 | 爆头倍率 | | 僵尸 | 头部脆弱系数 |
|---|---|---|---|---|
| 手枪 | 1.6 | | 行尸 / 奔袭者 / 肿胀者 | 1.0 |
| 冲锋枪 | 1.7 | | 破墙者（戴头盔） | 0.7 |
| 霰弹枪 | 1.75 | | 巨像（头部装甲） | 0.6 |
| 突击步枪 | 2.5 | | | |
| 狙击步枪（新） | 3.0 | | | |
| 轻机枪（新） | 1.8 | | | |
| 榴弹 | 无（范围伤害） | | | |

- 反馈：爆头时准星出现金色叉号，伤害数字变成金色，头部炸开血雾，爆头击杀时僵尸的头没了，配专门的音效。结算页显示爆头数和爆头率。
- 新卡牌："弱点打击"（稀有，爆头加成 +30%）、"稳定架势"（普通，瞄准时散布再降 25%）。

### 12.3 弹道

- 枪械的子弹不再是瞬间命中的射线。每颗子弹有初速，每一帧（1/60 秒）前进一段并受重力下坠，用这段线段扫描头和身体。
- 归零：枪口微微上抬，子弹在"归零距离"正好穿过准星，再远就开始掉。重力取 50 米/秒²（真实是 9.8，但真实子弹在 30 米内几乎不掉，感觉不出来）。

| 武器 | 初速 m/s | 归零 m | 射程 m | 射程尽头比准星低 |
|---|---|---|---|---|
| 手枪 | 160 | 10 | 20 | 约 20 厘米 |
| 冲锋枪 | 190 | 9 | 16 | 约 8 厘米 |
| 霰弹枪 | 130 | 6 | 11 | 约 8 厘米 |
| 突击步枪 | 240 | 20 | 32 | 约 17 厘米 |
| 狙击步枪 | 420 | 30 | 60 | 约 26 厘米 |
| 轻机枪 | 220 | 15 | 26 | 约 15 厘米 |

- 飞行时间约 0.1–0.15 秒，远处的奔袭者要稍微提前量。
- 墙（3.2 米高）挡子弹；路障（1.15 米）和炮塔（1.4 米）比眼睛（1.62 米）矮，平着打能从自家路障上方射过去，压低枪口就会打在路障上。子弹打到地面会溅起火星。
- 榴弹也有弹道：沿视线发射，受正常重力（9.8）抛物线下落，碰到地面、墙或僵尸就爆。平射大约 9 米落地，想打远要抬高枪口。
- 曳光就是子弹本身，跟着真实轨迹飞。

### 12.4 右键瞄准

- 按住右键瞄准（建造模式下右键仍然是拆除）。按武器不同用 0.12–0.35 秒举枪：视野缩小（手枪 1.25 倍，狙击 3.5 倍并出现瞄准镜画面），枪移到屏幕中央，散布降到腰射的 4%–70%，后坐力减半。
- 代价：瞄准时移动速度降低 45%，不能冲刺；换弹时会自动放下。
- 后坐力会真的把视线往上抬一点，松开扳机后慢慢回落；瞄准时减半。

### 12.5 局外成长（大厅）

**勋章**：只在局外使用的货币，一局结束（胜或负）时结算：

| 来源 | 勋章 |

| 撑过第 n 夜 | 4 + 2n（撑满 10 夜共 150） |
| 击败第 5 夜 / 第 10 夜首领 | 15 / 30 |
| 每 25 次击杀 | 1 |
| 每 10 次爆头击杀 | 1 |
| 通关 | 40 |
| 难度倍率 | 普通 ×1，困难 ×1.5，噩梦 ×2 |

死在第 3 夜大约 15 勋章，死在第 6 夜大约 70，通关一局约 270。全部买满的总价由 `sim:meta` 算出来写在下面，目标是普通玩家二三十局、熟练玩家十局左右买满。中途放弃一局（开新局覆盖检查点）也按已经撑过的夜数结算。

### 13.3 风险和开放问题

| Tailwind 的 Preflight 重置会改变现有界面（标题、按钮、输入框默认样式） | M8 先审全局样式；逐屏截图对比；出问题只在对应组件补样式 |
