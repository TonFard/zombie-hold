# 开放世界（废土 · Wasteland）

入口是单独的页面 `open.html`，代码在 `src/open/`。主菜单有「生存世界」「生化模式」两项（2026-11-15 接上），背包右下角和生化模式的面板里有「主菜单」回去；还没有提交。

## 用户要什么

- 2026-11-13：「我想做一个开放地图，从零收集资源的基于我们这个项目……不能很卡，要比较流畅。最好可以先把地图做出来，用我们的模型，写实的还是之前用的模型，现有的资源。还是我们这个游戏的底色，丧尸生存，升级。」参考 Road Survival: Bigger on the Inside（Steam 3947270）：搜刮 → 带回据点 → 升级 → 往更危险的地方走。
- 后面要加载具和汽油，所以地图要大；「最好像我的世界那样可以无限探索的，但是都要保证性能」；「之前的地图做的有点太 low 了，质感太差了」。
- 「我们还是需要有军事基地的，里面有大量的武器装备在里面，可以去探索搜寻物资。」
- 「房子里面都太空了。参考一下吃鸡和三角洲的房屋建设，东西要多一点。」（只参考「房间有用途、东西摆得满」这个做法，不照搬任何一款游戏的房子。）
- 2026-11-14：「我们的卡是 3070，如果都卡的话说明其他的机器更卡了，得好好兼容一下。」
- 2026-11-14（看了农场的截图）：屋外散落的东西「太挡了」；房子「很奇怪」，整体、内部布局、外观、房子和房子之间都要重新设计；要雨天和下雪；「玩法也要想想」；「营地是不需要的」；「可以捡东西，做各种可以捡的道具」；车的交互要好好做，「尤其是下车，还有加油」；人物状态要有饿、渴、冷。
- 2026-11-14：开局没有武器，要自己找；丧尸要多，晚上更多；「武器不能太多，武器是稀缺资源」；每种武器用不同的子弹；枪每类挑两到四把。
- 2026-11-14：车只有一辆；车上能放东西；能改装加装，改装件是专门做好的模型，要在世界里找。
- 2026-11-15：「生存世界中的武器解锁对应着守城武器解锁，还有生化模式武器解锁，生化模式还没做」；「守城模式……带入到生存模式里面」，「可以到一个地方激活守城模式。夜晚的时候或者白天的时候，或者其他的形式」；「还需要加一下敌人，敌人可以参考我们做的 csgo 真人对打的，他们有武器的，做的要像真人」——之后补充：「8v8 也是独立模式啊，只是参考里面的人机做到我们里面来，参考吃鸡的人机」（8v8 不并进来，只把那种人机做进生存世界）。
- 2026-11-15：CurseForge 上的「[TACZ + LRTactical] Stims & Stuffs」里的东西「可以加入进来，看看有没有可以加的」。

## 为什么是新模块

据点模式的 80×80 格写死在 37 个文件里；寻路每秒 8 次整图 Dijkstra，地面权重图 / 细节画布 / 烘焙光都按整图一张，放大会全面变慢。所以开放世界是同一个项目里的新模块，复用写实模型清单和加载（`realProps` 的归一化规则）、PBR 贴图、天空、雾、HDRI、后期、枪和视角模型。不改据点模式的任何东西。

## 世界是怎么来的

无限地图，不存任何数组：所有东西都是「种子 + 坐标」算出来的，走到哪生成到哪。

| 模块 | 做什么 |
|---|---|
| `world/roads.ts` | 480 米一格的路网，每格一个路口（位置随机抖动）。`i = 0` 那一列永远连着，是贯穿南北的公路。路口四周 64 米的路是笔直的。 |
| `world/terrain.ts` | 高度是 (x, z) 的函数：大丘陵 + 中丘陵 + 小起伏，离路远的地方有石山，低于水位（−13）的洼地是湖。路面和地点压平。 |
| `world/chunkgen.ts` | 地形块的数据。四叉树，第 L 级的块边长 64 × 2^L 米，每块都是 32 × 32 格（近处 2 米一格，最远 16 米一格）。 |
| `world/sites.ts` | 地点。每个路口按种子决定有没有、是哪种：起点、加油站、小镇、农场、货场、林间木屋、检查站、军事基地。出生点附近是固定的（原点 = 起点，一段路边停车带，没有房子；往北依次是加油站、小镇、军事基地，往南是农场），再远的随机，军事基地越远越多。一个地点的内容第一次被问到时一次算完并缓存。 |
| `world/houses.ts` + `housing.ts` | 房子。见下一节。 |
| `render/ground.ts` | 地形渲染，只生成、只画玩家周围的块，每帧有时间预算。看 1250 米远。 |
| `render/flora.ts` | 树、灌木、石头。近处是真模型，远处的树是两片交叉的面片（256 米一块合批），能看到 1 公里外的林子。 |
| `render/grass.ts` | 草。三层固定的「草皮」在着色器里跟着相机走，不占 CPU。 |
| `render/sitesView.ts` | 地点的渲染。720 米内加载，900 米外卸掉。 |
| `quality.ts` | 画质分档和自动调节。见「流畅」一节。 |
| `vehicles/` | 车。见最后一节。 |

## 房子和地点（2026-11-15 重做）

用户看了农场的截图说：屋外的东西「太挡了」，房子「很奇怪」——整体、内部布局、外观、房子和房子之间都有问题；「营地是不需要的」。所以这一版整个重做了。

平面图还是字符画（`houses.ts`），一个字符 = 1 米见方的一格，最后一行是正面（朝路）：

```
'##W##WW#####'      # 外墙   | 内墙   W 窗   D 外门   d 内门   . 地板
'#bn.|kko..f#'      b 床  n 床头柜  k 橱柜  o 灶  f 碗柜  t 桌  c 椅
'#b..|......#'      s 沙发  l 茶几  v 电视柜  w 衣柜  h 货架  x 箱子 ……
'W...d.cttc.W'
```

**16 种房子**：棚屋、工具棚、木屋、平房、农舍、长平房（ranch）、商店、修车铺、诊所、仓库、谷仓、营房、军械库、指挥所、岗亭、废墟。除了棚屋、工具棚、岗亭、废墟，每栋至少两个外门（进得去也跑得掉），门洞净宽至少 1 米。

**墙和门窗**（`housing.ts`）：外墙厚 0.26 米、隔墙 0.14 米（以前一格厚，屋里显得又挤又假）；窗有窗框和玻璃（一个地点的玻璃合成一个半透明网格，不用透射材质）；门有门框和门扇；门廊、台阶、雨棚和招牌墙、烟囱、车棚、披屋。

**屋里的东西**：平面图里只画大件家具，其余的自动添置——

1. 大件家具靠哪面墙、朝哪边是算出来的；桌面、货架每一层摆上东西（按房间用途从一副「牌」里抽）。
2. 墙边自动加杂物（箱子、桶、小柜子）。每放一件挡路的都确认一遍：从门口还能走到每一格，否则换一件不挡路的。
3. 墙上的挂画、挂钟、搁板、防毒面具。
4. 地上的零碎、地毯、吊灯。

**摆设里不放「看着能用、其实捡不了」的东西**：枪、近战武器、红色铁皮汽油桶、手电、急救箱这几样模型只留给真能捡的战利品（`game/items.ts`）。以前军械库墙上挂着步枪、架子上摆着手枪却拿不走，像是坏了。

**战利品的位置**只放在实测过的地方：站得住、够得着、中间没有墙挡着。

每栋房子输出一份 `Interior`：外轮廓、门口的点（宽门每米一个点）、屋里所有能站人的格子。战利品、丧尸都用这份数据。

**地点的布局**（`sites.ts`）：

| 地点 | 现在什么样 |
|---|---|
| 起点 | 公路边的一段停车带：皮卡、两台废车、几件行李。没有房子、没有围墙。 |
| 小镇 | 四个街区，约 23 栋：铺面贴着人行道（每个镇一定有商店、修车铺、诊所），住宅有栅栏围着的前院后院，一条小路通后巷，后面还有一排小房子；路边有废车和停车位。 |
| 军事基地 | 围墙围着的大院：中间一条大道，营房、车场、军械库、仓库、指挥所、停机坪、帐篷、油罐。 |
| 加油站、农场、木屋、货场、检查站 | 各是一个院子：房子、棚子、围栏按用途摆，中间留出空地（不再是满地零碎挡路）。 |

规模（`housetest.ts 12`，768 栋，全部走得通）：平房平均 57 件东西，农舍 48，长平房 64，商店 110，修车铺 48，诊所 56，仓库 104，谷仓 57，营房 73，军械库 126，指挥所 67。搭一栋 0.7 毫秒；生成一个小镇中位数 8.6 毫秒、基地 6.0 毫秒。

## 流畅

### 一直在做的

- 一个地点的墙、地板、屋顶合成一个网格，一次绘制（15 种贴图放在一张贴图数组里，按顶点选层）。
- 同一个模型在一个地点里的所有摆放是一个 InstancedMesh；每个模型有一份运行时简化出来的远景版，按距离逐个实例切换。
- 屋外的小东西 70 米外不画，不到 0.6 米的 38 米外不画。
- **屋里的东西按房子算**：相机离那栋房子的外墙 30 米以内才画（不到 0.6 米的小件 12 米），而且不投影。
- 阴影只覆盖玩家身边，跟着玩家走。
- 新地形每帧最多花 3 毫秒生成；模型用到才加载，贴图一帧传一两张，着色器异步编译。

### 2026-11-14 踩到的两个坑

1. **透射玻璃**（`KHR_materials_transmission`：挂钟、工业吊灯、发电机的玻璃罩）。画面里只要有一个这种材质，three.js 就先把所有不透明物体画进一张离屏贴图、再正式画一遍。营地小屋里 454 次绘制 / 562 万三角形，改成普通半透明玻璃以后是 290 次 / 337 万。处理在 `sitesView.ts` 的 `mergeParts`。以后加模型先跑 `node .logs/open/glbmats.mjs` 看一眼。
2. 屋里的东西原来和屋外的小东西用同一条 70 米规则，站在镇上就要画四周所有房子的家具：镇上 630 次绘制 / 299 万三角形，按房子算以后是 250 次 / 136 万。

### 画质分档（`quality.ts`）

只降渲染分辨率救不了所有机器：卡在像素上（核显、高分屏）降分辨率有用，卡在顶点和绘制次数上降了没用。所以分四档，每档管这些：

| | 高 | 中 | 低 | 最低 |
|---|---|---|---|---|
| 分辨率上限（相对 CSS 像素） | 1.25 | 1 | 1 | 1 |
| 阴影贴图 / 范围 | 2048 / ±45 m | 1536 / ±36 m | 1024 / ±26 m | 无 |
| 树的真模型画到 | 68 m | 52 m | 38 m | 30 m |
| 面片树画到 | 1050 m | 1050 m | 800 m | 600 m |
| 草的密度 | 100% | 70% | 45% | 22% |
| 光晕 | 有 | 有 | 无 | 无 |
| 小东西的距离 | ×1 | ×0.8 | ×0.6 | ×0.5 |

- **自动**（默认）：开局按显卡名字猜一档（核显 → 低，老独显 → 中，RTX 一类 → 高），然后看帧时间。连续慢了一秒半才动手：先降分辨率，降到底发现没用就还回去、改降档；怎么调都没用（比如浏览器把帧率限在 30）就全部还回去，过几分钟再试。快了再一步一步升回来，升完掉到 54 帧以下就撤回。慢到 10 帧以下并且持续 6 秒，直接降到底。
- 没有用上显卡（软件渲染：浏览器关了硬件加速、驱动被拉黑）时开局提示 20 秒。这种情况最低档也只有每秒不到一帧，调画质救不回来。
- **F4** 在 自动 / 最低 / 低 / 中 / 高 之间切换，选择记在本机。
- **F3** 面板显示帧率、绘制次数、三角形数、当前画质和分辨率、**显卡名字**（笔记本上能看出是不是跑在核显上）。
- `?q=min|low|mid|high` 固定档位，分辨率也不动（测量用，不保存）。

同一个位置、2133 × 1333 下各档的工作量（绘制次数 / 三角形）：

| 位置 | 高 | 中 | 低 | 最低 |
|---|---|---|---|---|
| 出生点 | 278 / 347 万 | 279 / 207 万 | 265 / 108 万 | 188 / 55 万 |
| 小镇中心 | 266 / 136 万 | 263 / 103 万 | 242 / 79 万 | 221 / 53 万 |
| 树林 | 225 / 407 万 | 225 / 279 万 | 210 / 189 万 | 192 / 86 万 |

## 怎么验证

测试脚本都在 `.logs/open/`（不进仓库），用 `npx tsx` 在项目根目录跑：

| 脚本 | 查什么 |
|---|---|
| `housetest.ts [种子数]` | 平面图的规矩；每种房子 4 个朝向 × N 个种子搭出来，用真实的碰撞体从门外做一次洪水填充，报告走不到的格子。 |
| `coltest.ts [种子数]` | 起点（平地、离路近、停得下车）和每种地点：房子、战利品、车位各有多少，人走得到、车开得到的面积。 |
| `contentbench.ts` | 每种地点生成内容要多少毫秒。 |
| `qualitytest.ts` | 拿 11 种「假机器」跑自动画质的逻辑（强机器不乱调、核显降分辨率、老独显降档、帧率被限住时还回去……），再查 17 个显卡名字猜得对不对。 |
| `glbmats.mjs` | 哪些模型带透射 / 半透明材质。 |
| `gametest.ts` | 玩法层的纯逻辑：物品表完整、背包重量、多久饿死 / 渴死 / 冻死、每种地方多少个位置才有一把枪。 |

量帧率的注意事项：

- 用不会自动刷新的开发服务器：`npx vite --config .logs/open/vite.config.mjs`（端口 5176）。主配置在任何人改了 `src/` 或 `public/` 时会整页刷新，跑到一半的测试就废了。
- 别的会话的无头浏览器也在用这块显卡，同一个测试前后能差两三倍。先看 `nvidia-smi`；比较各档要在同一个页面里轮流切（`q3.json`）；绘制次数和三角形数才是稳的。
- 按用户屏幕的实际渲染尺寸测：2560 × 1600、缩放 150% → 2133 × 1333，像素是 1600 × 900 的两倍。
- `?cap=60` 把帧率限在 60，测走路时的卡顿（`in12.json`）。
- `sh .logs/open/check.sh` 只对 `src/open` 做类型检查（十几秒）；`sh .logs/open/shot.sh 步骤.json ["&参数"] [宽] [高]` 开无头浏览器跑一组步骤（同时最多两个）。

## 玩法（2026-11-14）

**一局怎么玩**：空着手在路边醒来 → 进屋搜吃的喝的、找一件防身的家伙 → 找汽油把唯一的那台皮卡开起来 → 加油站、小镇、军事基地，离起点越远越危险、东西越好。饿、渴、冷都会要命；天黑以后丧尸翻倍。死了身上的东西掉在原地（地图上标「遗物」），车上的东西还在车上，人回到起点重新醒来。没有营地、没有建造。

### 模块怎么分

模块之间只通过 `src/open/game/api.ts` 里的接口互相调用，各管各的文件：

| 模块 | 文件 | 管什么 |
|---|---|---|
| 玩法层 | `game/game.ts` | 背包、车厢、拾取、目标、等级、死亡和重来、存档、界面；建 `GameCtx` 给别的模块用 |
| 物品 | `game/items.ts` | 58 种物品、战利品表 |
| 生存状态 | `game/survival.ts` | 背包（按重量）、生命 / 饱 / 水 / 体温 / 体力。纯逻辑，不碰 three 和界面 |
| 地上的东西 | `game/pickups.ts` | 地点里的战利品、丢下的东西；画法和准星选中 |
| 存档 | `game/save.ts` | localStorage，一个种子一份 |
| 武器图鉴 | `game/unlocks.ts`、`gunbook.ts` | 生存世界、守城模式、生化模式共用的「哪些枪解锁了」 |
| 守城 | `game/siege.ts` | 据点的发电机发动起来，守住一波波丧尸 |
| 生化模式 | `game/bio.ts` | `open.html?mode=bio`，单独的一局 |
| 打谁 | `game/combat.ts` | 玩家的子弹、近战、手雷打到丧尸还是人（`CombatApi`） |
| 带枪的人 | `combat/raiders.ts`、`raider-*.ts` | 敌人、生化模式里的同伴（`RaidersApi`） |
| 天气 | `weather.ts` | 雨、雪、气温、风（`WeatherApi`） |
| 丧尸 | `combat/horde.ts` | 刷新、行为、渲染、受伤（`HordeApi`） |
| 武器 | `combat/arsenal.ts` | 枪、近战、弹药、视角模型、准星（`ArsenalApi`） |
| 车 | `vehicles/` | 上下车、油、改装件；共享状态 `CAR` |

`main.ts` 里每个模块的调用都包在 `safe()` 里，建模块包在 `make()` 里（起不来就用 `game/nulls.ts` 的空实现顶上）：一个模块出错不会拖垮整个页面，出过错的模块名记在 `window.__open.failed` 里。

### 物品和战利品

- 种类：食物、饮料、药品、取暖、弹药（6 种口径）、手雷、汽油桶、装备（厚外套、背包、手电筒）、枪（18 把）、近战武器（5 种）、皮卡改装件（6 种）。
- **吃、喝、包扎、打针都要时间**（1.4–5 秒，`ItemDef.time`）：手上的武器先放下，这几秒不能开枪，人能走；切武器、上车、死了就打断，东西不会被用掉。坐在车里用是马上生效。已经满了的不让白白用掉。
- **2026-11-15 新加的六样**（来自消耗品包，见下面「消耗品包」）：肾上腺素针（体力回满，30 秒跑不累、腿脚快一成）、镇痛针（回 40 血，40 秒挨打少疼三成）、清凉油、香烟、奶酪、手雷（按 Q 扔，引信 3.2 秒，半径 7.5 米，自己也会被炸）。针剂主要在诊所和军营，手雷只在军营和守城的奖励里。
- 每个地点有一批「可能有东西的位置」（`SiteContent.loot`，带一个 `place`：住家 / 商店 / 仓库 / 诊所 / 军营 / 屋外的车 / 加油站）。每个位置有没有东西、是什么，都按世界种子算，所以同一个世界每次都一样；捡走的记进存档，搜过的房子一直是空的。
- **枪是稀缺资源**。用 `gametest.ts` 量出来的：民宅大约每 112 个位置一把（只有一级的手枪和短管猎枪），仓库 / 修车铺每 87 个，军营每 24 个（三四级的好枪只在这里）；商店、诊所、加油站没有枪。找到的枪里只剩小半个弹匣。
- 每把枪只吃自己口径的子弹：9 毫米、.45、马格南、12 号霰弹、5.56、7.62。民用弹药以 9 毫米和霰弹为主，步枪弹主要在军营。
- 地上的东西：同一种模型一个 `InstancedMesh`，只画 38 米以内的；每件东西上方一个小光点（全部光点一次绘制，颜色按稀有度）。准星指着、2.9 米以内、中间没有墙才能捡。

### 生存状态

一个游戏日 = 24 分钟。下面的数都是 `gametest.ts` 量的：

| | |
|---|---|
| 不吃 | 30 分钟饿到底，35 分钟饿死 |
| 不喝 | 22 分钟渴到底，26 分钟渴死 |
| 连续跑 | 14 秒（体力用光要缓到 15% 才能再跑） |
| 3℃ 的夜里站在外面 | 12.6 分钟冻透 |
| 5℃ 大雨夜 | 6.6 分钟冻透；穿着厚外套不掉体温 |
| −6℃ 雪天 | 4.3 分钟冻透、7 分钟冻死；穿厚外套 12 分钟 |
| −6℃ 躲在屋里 | 不穿外套 21 分钟才冻透；穿着外套 1 分钟内缓过来 |
| −6℃ 坐在车里 | 熄火 10 分钟冻透；开着发动机 1 分钟多缓过来 |

体感温度 = 气温 + 遮蔽（屋里 +10、熄火的车 +6、开着发动机的车 +18，都没有风；屋外 −风×4）+ 厚外套 10 + 暖宝宝 10 + 跑步 3 − 淋湿×8。外套让风和淋湿的影响减半。低于 8℃ 开始掉体温。饿、渴、冷到底以后掉血；三样都在一半以上、8 秒没受伤时慢慢回血。背得超重走不快。

### 天气（`weather.ts`、`weather-fx.ts`、`weather-sound.ts`）

- 五种：晴、阴、雨、雷暴、雪。时间表按世界种子和游戏里的日期 / 钟点算（存档只存当前是哪种）。第一天中午以前一定是晴天，第一场坏天气一定是雨；默认种子第一天 14 点多下雨、17 点多下雪。
- 气温：一天里凌晨 5 点最冷、下午 3 点最暖；晴 10–18℃、雨 3–9℃、雪 −7–0℃。下的是雨还是雪看气温（1.5℃ 以上是雨，−1℃ 以下是雪），冷锋过来雨自己会变成雪。
- 画面：雨丝、雪花各是一个 `InstancedMesh`（顶点着色器里动），屋顶和雨棚下面不落（用 `Sites.coversNear`）；地面、草、树的着色器里有打湿变暗、积水和涟漪、积雪（`render/wx.ts` 的 `WX`）。光、雾、云、天顶颜色每帧在钟定好的基础上再改；闪电只是把已有的太阳和天光拉亮，不加灯。房子、道具、车上还不会湿、不会积雪。
- 声音：雨声（屋里、车里发闷）、风声、按距离延迟的雷声。
- 花销：晴 / 雷暴 / 雪在同一个页面里轮流测，绘制次数 192 → 193，三角形 345 万 → 349 万，平均帧时间没有差别（4.5–5.2 毫秒，2133×1333 高画质）。
- 调试：`?weather=clear|cloudy|rain|storm|snow` 固定一种；`__open.weather.set(kind, true)`。

### 武器（`combat/arsenal.ts` 和 `gun-*` / `melee-view.ts` / `fx-pool.ts`）

- 开局空手（拳头）。两个枪位（1、2）+ 一个近战位（3），再按一次手上那个键 = 收起来；滚轮切换；R 换弹；G 把手上的丢在地上；右键瞄准（视野 62° → 24°，鼠标跟着变慢，走路速度 ×0.6）。跑着不能开枪，按住开火 / 瞄准就不跑。

- 近战：棒球棍、撬棍、手斧、砍刀、大锤；挥一下耗体力，体力不够时又慢又轻。

- 调试：`__open.arsenal.debugGive('ak47')`（给枪和三个弹匣的子弹）、`.state()`；`?give=ak47,bat`。
- 还不好的：拳头的姿势有点别扭；AK、RPK、M870、UMP45、双管猎枪的机瞄挡住了屏幕下半中间；夜里枪比周围亮；没有弹壳和弹孔。声音和手感没有人实际试过。

### 丧尸（`combat/horde.ts` 和 `zombie-*.ts`）

- **住在哪**（`zombie-spawn.ts`）：世界上到处是「坑位」，位置和种类按种子算，所以同一栋房子每次去都是那几只。地点里每栋房子按大小和危险等级住 0–5 只，院子、穿过地点的路上再放一批；野地里 64 米一格，大约十格一只。夜里每处多出差不多一倍。玩家走近了坑位才变成真的丧尸，打死以后那个坑位空一个游戏日以上。出生点和它周围不放。
- **同时最多**：白天约 32 只，夜里 45 只。
- **五种**（数值沿用据点模式的表，速度另定：人走 4.3、跑 7.0 米每秒）：行尸（追人 2.2 米每秒，走着就能甩开）、奔袭者（5.0，夜里和危险的地方多）、爬行者（1.25）；危险等级 3 以上偶尔有肿胀者、重装（正面有钢板）。
- **挨打的节奏**（站着不动量的）：一只行尸把满血的人打死要 18 秒左右；被三只以上围住，白天约 13 秒、夜里约 8 秒（同时出手的只数有上限：白天一只、夜里两只）。前摇 0.6 秒，退开半步就打空。出手时站在离人 1.05 米左右，不会贴进镜头里。
- **找路**（`zombie-nav.ts`）：每个地点一张格子图，会绕墙、走门；听见枪声、喇叭、引擎和撞车声会过来看（`HordeApi.noise`）。
- **和车**：开车撞上去按车速算伤害（`CAR.ram` / `onRam`），装了防撞杠撞得更狠（×1.6）；人坐在车里丧尸照样能打到，装了车窗护网以后伤害只剩三成（`CAR.armor`）。
- **画法**（`zombie-view.ts`）：48 个带骨骼的实例提前建好、轮流用，远了换低模。花销（2133×1333）：视野里 20 只 +39 次绘制，45 只 +71 次，45 只围上来 +108 次（一共 300 次上下）；`horde.update` 平均不到 0.3 毫秒。
- 调试：`?zombies=0` 不放；`__open.horde.debugSpawn(n, kind, dist)`、`.list()`、`.debugKillAll()`；无头测试 `npx tsx .logs/open/zedtest.ts`。
- **被围住走不快**（`HordeApi.grip`）：贴在身上的丧尸一只让人慢 15%，三只以上慢 45%。量过：平时走 4.2 米每秒；被五只行尸围住时 3 秒走出 9 米（挤得出去，但挨了 11 点血），甩开以后跑步 6.1 米每秒。
- **进存档**：打空了的坑位和还要空多久（`HordeApi.save / load`）。清过的房子重开页面以后还是清过的。
- 还不好的：围着栅栏的农场 / 基地外面的丧尸追到栅栏可能就放弃了；白天眼睛也发光；声音没有人实际听过。

### 武器图鉴：三个模式共用的解锁（`game/unlocks.ts`，2026-11-15）

生存世界的 18 把枪在守城模式（主游戏）里都有同名的型号，所以解锁按型号算，三边互认：

| 在哪解锁 | 怎么解锁 | 另外两边怎么认 |
|---|---|---|
| 生存世界 | 捡到过一把（拿到手上、收进背包都算） | 守城模式直接拥有这个型号；生化模式开局能挑 |
| 守城模式 | 原来的规矩：熟练度 + 勋章 | 生存世界据点的军械箱能借；生化模式开局能挑 |
| 生化模式 | 每局结算给军功，用军功换（按稀有度 3 / 6 / 10 / 15） | 守城模式直接拥有；军械箱能借 |

- 按 B 或者背包右下角看图鉴：每把枪是哪来的。
- **存在哪**：这台电脑的 localStorage 里一份（`zh.open.unlocks.1`，没登录也能用）。主游戏的进度只存在服务器上；这个浏览器登录过主游戏的话（localStorage 里有登录信息），启动时把服务器存档里守城模式已有的型号读下来（只读）。**往服务器写要玩家在图鉴里点一次「同步到守城模式」**——那份存档是主游戏的全部进度，不能悄悄改；点过以后，这边新解锁的自动追加进存档的 `meta.guns`：整份存档原样读回、只动这一个数组再写回去，版本号对不上（别处刚写过）就重新读一遍再写；每次写之前，原来那份存档在本机留一份（localStorage 的 `zh.open.cloudsave.bak`）。主游戏的代码一行没改：它读存档时本来就认 `meta.guns`。
- **没碰的规矩**：主游戏解锁一个「类别」（冲锋枪、步枪……）要先把上一类练到精通。这里只解锁型号，不解锁类别——在生存世界捡到 AK，守城模式里要等步枪这一类解锁了才用得上它。
- 没登录、没点过同步、或者连不上服务器：解锁只记在本机。新号在主游戏里还没有存档时不写（等主游戏建了存档再说）。`?cloud=0` 完全不连服务器。
- 量过的（假的存档服务器 `.logs/open/mockcloud.mjs`，`n2.json`）：读到服务器上已有的两把；本机新解锁三把，其中两把要勋章的追加进了 `meta.guns`、不要勋章的 M870 没有写；中途故意让版本号对不上一次，重读后写成功；存档的其他字段逐个比对没有变化。**没有对着真的服务器试过。**

### 守城：在据点里守发电机（`game/siege.ts`，2026-11-15）

- **在哪**：加油站、货场、公路检查站、军事基地，每个都有一台柴油发电机，旁边一摞军用木箱（军械箱）。走到 3 米以内，地图上标出「据点」。三个种子、南北九公里范围内 102 个这样的地点全都有发电机和军械箱、周围站得住人（`npx tsx .logs/open/siegetest.ts`）。加油站和货场的发电机是这次加的，放的时候不用随机数、不加战利品位置，所以这些地点别的东西一样不变，旧存档不受影响。
- **怎么开始**：按住 F 1.6 秒。白天夜里都行。25 秒准备，然后 3–6 波：基础 3 波，危险等级 3 以上 +1，5 级 +1，夜里再 +1；每波 4 + 2.5×第几波 + 1.5×等级 只，夜里多四分之一（一级的加油站白天三波一共 32 只；四级的基地夜里五波一共 110 只）。行尸为主，越往后奔袭者越多，危险的地方后几波有肿胀者和重装。
- **守什么**：发电机也会被咬（生命 600 + 120×等级；量过：被两只同时咬大约每秒掉 10 点），四成丧尸奔着它去、六成奔着人。波与波之间歇 16 秒，发电机回 15%。
- **军械箱**（开始时自动弹出来，之后在发电机旁边按 E）：借一把图鉴里解锁了的枪，子弹管够，守完收回；借的枪丢不掉、死了不掉、不进存档。
- **没守住**：发电机被咬坏、人死了、离开 75 米以上超过 12 秒。不扣东西，可以马上再来。**守住**：经验 120 + 50×等级（夜里 +80），发电机旁边一堆补给——手上的枪用的子弹、急救包、绷带、口粮、水、手雷，等级高的有针剂；夜里一定有一把枪，白天按等级有机会。同一个据点守住以后隔 3 天才能再守。
- 守城期间周围不再另外刷丧尸（`HordeApi.ambient`）；危险等级 3 以上的据点有一半的机会，中间某一波枪声把一伙带枪的人引过来。
- 打到一半关掉页面 = 没守住。
- 量过的（无头浏览器，`n5.json` / `n6.json` / `n8.json`）：加油站白天三波走完——借枪、三波、奖励落在发电机旁边空着的一侧、借的枪收回、同一个据点提示「3 天以后再来」；发电机被咬坏 = 没守住，借的枪收回；守到一半人死了，借的枪不掉在地上。花销：加油站白天一波 10 只围上来 279–285 次绘制（1600×900）；军事基地夜里 22–24 只 230–242 次绘制、84 万三角形（2133×1333）。
- 没试过的：五六波的整场从头打到尾要多久、难不难（上面是用脚本直接清怪走完流程的）；带枪的人中途摸过来那一下；发电机的嗡嗡声没有人听过。

### 生化模式（`game/bio.ts`，`open.html?mode=bio`，2026-11-15）

单独的一局：不读也不写生存世界的存档，没有饿、渴、冷，没有经验。入口：背包右下角「生化模式」，或者直接开这个地址。

- **场地**：起点往北第二个路口的那个镇子，以街口为圆心一个圈，出不去。从下午四点半打到天黑。
- **开局**：从图鉴里已经解锁的枪里挑一把（子弹管够），另外给一把手枪、一把砍刀、两颗手雷、两卷绷带、一支肾上腺素针。你和七个带枪的幸存者（`RaidersApi` 的 `ally`）站在街口。
- **20 秒后**：离你最远的那个人变成母体（丧尸种类 `mother`）。之后每 14 秒外面再进来几只感染者，直到母体被打死。
- **感染**：幸存者被母体咬一口、被别的感染者咬第二口就变成感染者（奔袭者，生命 160）。
- **你被咬倒** = 被感染：只剩一双爪子（`ArsenalApi.claws`），丧尸不再理你（`HordeApi.passive`），原来的同伴开始朝你开枪（`RaidersApi.setSide`）。你很耐打、跑不累；被打倒了 5 秒以后在别处再站起来。用爪子打倒的人会变成感染者。
- **胜负**：4 分钟到了还有人活着，或者母体和感染者全被打死 → 人类赢；所有人都被感染 → 感染者赢。
- 镇上的房子里不放战利品（这一局不存档，不然每局都能重新搜一遍）。感染者（玩家）受到的伤害只算四分之一。
- 量过的（`n7.json` / `n11.json` / `n12.json`）：开局七个同伴各拿各的枪、20 秒后离你最远的那个变成母体、同伴被咬会变成感染者、你被咬倒以后同伴全部倒戈、用爪子抓倒的人变成感染者、天黑结算、用军功换枪、再来一局状态全部复位、不写生存世界的存档。花销（2133×1333，下着雨）：开局前 143 次绘制，七个同伴站出来 177，打起来 296–300 次、163 万三角形；`raiders.update` 平均 0.10 毫秒、`horde.update` 0.13 毫秒。
- 没试过的：一整局四分钟从头打到尾的节奏和胜率（上面都是脚本跳过等待走流程）；母体现在只是一只血很厚的奔袭者，专门的数值和体型还在做。
- **军功**：参加 1；作为人类活到最后 +5；每打死 6 只 +1（最多 4）；母体被打死 +1，是你打死的 +4；作为感染者每亲手感染一个 +1（最多 5），感染者赢了 +2。结算界面上直接用军功换图鉴里没解锁的枪。

- 用了什么：六样东西的模型和第一人称的使用动作（肾上腺素针、香烟、镇痛针、清凉油、奶酪、手雷）。**没有用包里的声音**（有些文件名看上去出自别的商业游戏），声音是自己合成的。
- 没有 `public/stims/` 的机器上照常玩：这几样东西在地上用现成的道具模型染个色，用的时候只是把手放下去。

### 成长

打死丧尸、第一次到一个地点、每活过一天、完成目标都给经验。每升一级：多背 2 千克、更耐跑（+6%）、更耐饿耐渴（+4%）。左上角一直有一条当前目标（找吃喝 → 找近战武器 → 找汽油 → 加油站 → 找枪 → 熬过第一夜 → 小镇 → 军事基地 → 守住一个据点）。打死一个带枪的人 45 经验（爆头 60）。

### 按键

E 拾取 / 上下车 / 军械箱 · F 第二动作（枪收进背包、加油、装改装件、按住发动发电机）· Tab 背包（站在车尾时同时打开车厢）· 1 2 3 武器 · R 换弹 · Q 手雷 · 4 吃 · 5 喝 · 6 治疗 · 7 取暖 · 8 打针 · B 武器图鉴 · T 手电（先得捡到）· M 地图 · F3 性能 · F4 画质。N（跳时间）只在开着 F3 面板时有效。

### 存档

每 20 秒、切到后台、关页面、死的那一刻自动存：人在哪、几点、生存状态、背包、车厢、手上的武器、车（位置 / 油 / 改装件）、捡走了哪些、丢下的东西、哪些地方的丧尸清过了、哪几伙带枪的人打掉了、哪些据点守住过、天气、发现过的地点、等级和目标。武器图鉴另存一份（不跟着种子，「新开一局」也不清）。生化模式不读不写这份存档。死了以后关掉页面，下次打开直接在起点醒来。背包界面右下角「新开一局」（点两下）清档。`?nosave=1` 不读不写存档，`?new=1` 先清档。`save.ts` 里的 `LAYOUT` 在地点 / 房子的生成方式变了以后要加一（旧存档里的坐标对不上了）。

## 车（2026-11-14）

用户要把 Vettura（Minecraft 车辆模组，作者 Antaurora）的车放进游戏，试过四台后决定**只保留 T15 皮卡**；后来又定了：**整个世界只有这一台车**，车上能放东西，能改装。

- **素材只在本机**：Vettura 没有公开授权，`public/vehicles/` 在 `.gitignore` 里；发布脚本从 `git archive HEAD` 打包，所以不会进公开发布包。重新生成：`python -I scripts/tools/vehicles-import.py`（读 `.vendor/vettura/x/`，即 Vettura 1.2.0 jar 解出来的资源）。没有这个目录时开放世界照常运行，只是没车。
- **转换**：`.vxmesh.json` 网格按（骨骼, 车漆 / 第二车漆 / 普通, 玻璃, 灯）合并；折边平滑法线；LabPBR 贴图 → 颜色 / 法线（DirectX 朝向）/ ORM（粗糙度最低 0.25、金属 0.38，不然太阳高光在 bloom 里整片发光）。T15 的物理参数在 Vettura 的 Java 代码里，按模型量的轴距 2.85 m、轮距、轮胎半径 0.359 m 配了一套。
- **物理**（`src/open/vehicles/physics.ts`，120 Hz）：刚体 + 每轮一根射线的悬挂（弹簧、阻尼、防倾杆、侧倾阻尼）+ 轮胎侧偏角曲线和摩擦圆 + 扭矩曲线 / 齿比 / 自动挡；倒车最快 25 km/h；没人开、停稳 1.5 秒就休眠。无头测试：`npx tsx .logs/veh/sim.ts pickup_t15`（0-100 约 15 秒、极速 145、100-0 刹车 51 米、颠簸路和急转不翻）。
- **上下车**：E 上车（车周围 1.6 米以内，哪一侧都行）。E 下车：车速 12 km/h 以下时先自动刹停再下，更快只提示「降到 12 km/h 以下才能下车」。下车点依次试驾驶侧门外 → 副驾侧 → 车尾 → 车头 → 往外一圈圈找到 22 米，总能给出一个站得住的位置（墙、树、水、陡坡都试过，`.logs/veh/exit.ts` 79 项）。下了车的车是驻车状态（四轮锁死、熄火），30° 的坡上不溜。
- **油**：油箱 45 升，开局只有 8 升。公路 40–50 km/h 约 1.7 升 / 公里，70–85 km/h 约 3.0，地板油 6.1；野地 40–50 km/h 约 4.0（越野胎 3.3）；怠速 5.4 升 / 小时。没油熄火，还能上车但打不着。仪表盘上有油表、升数、还能开多远、低油量（黄）和快没油（红、闪）。
- **加油**：汽油桶——站在车旁按住 F 2.5 秒倒进去 10 升（油箱装不下一整桶时不让倒）。加油机——车停在 5 米以内、人站在车旁按住 F，每秒 3.5 升，松手就停。每个加油站的存油按种子定（26–160 升），大约三成是干的（出生点 0.9 公里以内的不会干），存档里记着还剩多少。
- **改装件**（6 种，世界里找到 `part_<id>`，站在车旁按住 F 3 秒装上，车上能看到对应的模型）：防撞杠（撞丧尸伤害 ×1.6、车几乎不减速）、车顶行李架（车厢 60 → 100 千克）、副油箱（+30 升）、车顶射灯（车灯更亮更宽更远）、越野胎（野地抓地 0.8 → 0.98）、车窗护网（人在车里时丧尸伤害 ×0.3）。状态放在 `game/api.ts` 的 `CAR` 里，丧尸模块读它。
- **车厢**：站在车尾按 Tab，背包和车厢并排，能互相挪。车上的东西死了也不丢。
- **声音会引丧尸**：引擎 25–60 米、喇叭 120 米、撞车 40–90 米。
- **别的键**：WASD 开，空格手刹，V 车外跟车 / 车内视角，H 喇叭，L 车灯（天黑自动开，一盏共用的 SpotLight）。车挡人、人能站车顶；车撞墙 / 树 / 石头有冲量和撞击声。
- **绘制次数**（高画质）：停着 6 米处 18 次 / 10 万三角形，22 米 11 次，60 米以外 5 次；开车时车外视角 31 次，六个改装件全装上 38 次。不动的骨骼按材质合并了，阴影用一个低模代替。
- `?cars=0` 不放车（测帧率对比用）。无头测试都在 `.logs/veh/`：`sim.ts pickup_t15`（物理）、`park.ts`（坡上驻车）、`exit.ts`（下车点、油、改装件、存档）。
- 没验证的：倒油、加油机、装改装件的声音没人听过；油箱盖开的角度没看清；只有 T15 有改装件的模型。
- 代码里还留着摩托（压弯、前叉、后摇臂）和蝴蝶门的分支，现在用不到。
